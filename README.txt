TVDeck – build instructions (no coding needed)

1. Create a NEW private repository on github.com (e.g. "TVDeck").
2. Upload everything inside this folder (including the hidden .github folder).
3. Open the Actions tab. "Build APK" runs automatically (5-10 minutes).
4. When it has a green tick, open it and download the "TVDeck-apk" artifact.
5. Unzip it, copy app-release.apk to your phone and install it.

If the build shows a red cross, copy the error lines (they contain "e:") and send them to Claude.
