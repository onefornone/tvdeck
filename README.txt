TVDeck 2.1 – build instructions (no coding needed)

1. On GitHub open your TVDeck repository. Delete the old files (or create a new repository).
2. Upload everything inside this folder (including the hidden .github folder).
3. Open the Actions tab. "Build APK" runs automatically (5-10 minutes).
4. When it has a green tick, download the "TVDeck-apk" artifact, unzip it and install app-release.apk.
   (It installs over the old TVDeck version.)

If the build shows a red cross, copy the error lines (they contain "e:") and send them to Claude.
